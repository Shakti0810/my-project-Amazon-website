 AMAZON WEBSITE CLONE

A front-end clone of the Amazon website created using **HTML5 and CSS3**. This project was built to practice web development concepts such as webpage structure, navigation bars, layouts, product sections, and styling.

 PROJECT OVERVIEW

This project recreates the visual layout of an Amazon-style e-commerce website. It includes a navigation bar, search bar, product/category sections, promotional content, and footer.

> This project is created for educational and learning purposes and is not an official Amazon website.

 FEATURES

- Amazon-style navigation bar
- Search bar
- Location and account sections
- Product/category sections
- Promotional banners
- Product cards and images
- Footer section
- Clean and structured UI

 TECHNOLOGIES USED

- HTML5
- CSS3
- Flexbox
